# Подарок Оле

Личный сайт-поздравление с фотографиями, видео и голосовыми воспоминаниями.

Статический HTML, CSS и JavaScript. Сервер, база данных и регистрация не нужны.

## Локальный просмотр

Нужен Node.js 22 или новее. Внешних зависимостей нет.

```sh
npm start
```

Откройте `http://127.0.0.1:4173/`.

## Проверка и сборка

```sh
npm test
npm run check
npm run build
```

Готовый сайт находится в `dist/`. Исходный код хранится в `main`, готовая версия сайта — в `gh-pages`. GitHub Pages автоматически публикует обновления `gh-pages`.

После согласования и коммита изменений публикация запускается командой `npm run publish:pages`. Она проверяет сайт, собирает его и отправляет готовые файлы в ветку публикации. Нужны существующая авторизация GitHub CLI и права записи в этот репозиторий.

Содержимое воспоминаний задаётся в `site/data/memories.js`. Общие компоненты ленты, просмотра и плеера находятся в `site/app.js`. Фотографии сохранены в исходных цветах; тематические иллюстрации созданы отдельно.

Поисковая индексация страницы отключена через метатег `robots` и `robots.txt`. Сайт доступен по ссылке без пароля.
